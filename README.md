# Java Practice

A collection of Java exercises covering core programming fundamentals, organized by topic.

## Topics Covered

- Variables and data types
- Operators
- Flow control (if/else, loops)
- Arrays
- Switch-case statements
- String manipulation

## Structure

Source files are organized under `practice_java/src/in/obaid`, with one package per topic (`arrays`, `flowcontrol`, `loops`, `operator`, `stringmanipulation`, `switchcase`, `variables`).

This repository is used for ongoing practice of core Java and JavaScript concepts rather than as a production project.
